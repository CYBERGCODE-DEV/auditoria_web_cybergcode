CYBERGCODE WEB AUDIT INTELLIGENCE v0.8.1

1. Descomprimir este ZIP.
2. Copiar TODOS los archivos a la raíz del repositorio GitHub conectado a Vercel.
   La raíz debe contener: package.json, vercel.json, api/, lib/, public/, test/.
3. Commit + push a la rama de producción.
4. En Vercel comprobar que el deployment corresponde al commit nuevo y promoverlo a Production.
5. Abrir https://auditoria-web-cybergcode.vercel.app/ y confirmar: ENGINE 0.8.1.
6. Hacer Ctrl+F5 una vez.
7. Iniciar auditoría. El loader correcto debe:
   - ocupar toda la pantalla;
   - usar tema oscuro azul/cyan/violeta;
   - mostrar la marca CYBERGCODE;
   - mostrar el dominio auditado;
   - buscar y mostrar el logo real del dominio en el centro;
   - mostrar tiempo transcurrido real, no porcentaje ficticio;
   - indicar fallback textual si el dominio no expone un logo seguro/usable.

Si la web sigue mostrando ENGINE 0.7.0, Vercel sigue apuntando al deployment/repositorio/root directory anterior.
